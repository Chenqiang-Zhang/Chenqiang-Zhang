I am a graduate student in information science at Osaka University. I build and study interactive AI systems—from experiments on how people perceive machine-mediated dialogue, to personalized conversational agents and dependable physical automation.

## Research & engineering

| Track | Current focus |
| --- | --- |
| 🧠 **Human–AI Interaction** | How machine translation and conversational cues affect people's judgments of whether a dialogue partner is human or AI. |
| 🌸 **Conversational AI** | Persona-conditioned dialogue, lightweight interactive characters, and interpretable post-training experiments. |
| ⚙️ **Physical RPA** | Vision-guided automation that interacts with existing computer systems, with an emphasis on verification and safe failure handling. |

## Selected work

### MMTT — Machine-Translation-Mediated Turing Test

A research system for studying human/AI identity judgments in real-time multilingual dialogue. The current work treats translation, prompting, and interaction timing as experimental variables rather than hiding them inside a single black-box score.

`Human–AI interaction` · `LLM evaluation` · `Dialogue systems` · `Signal detection theory`

### [AIRI Lite](https://github.com/Chenqiang-Zhang/airi-lite)

A small, self-owned Live2D companion prototype with an editable persona, streamed dialogue, and browser speech output. It explores the smallest useful loop for an expressive character agent without inheriting a full monorepo.

`Vue` · `TypeScript` · `Persona design` · `Streaming chat`

### [Personalized Dialogue with Prompt-Tuning](https://github.com/Chenqiang-Zhang/Prompt-Tuning)

A reproducible implementation of persona-conditioned soft-prompt tuning with modern open models, designed to separate what the training objective improves from what it does not establish about human-likeness.

`Python` · `PyTorch` · `PEFT` · `Dialogue research`

### Physical RPA at SocioFuture

During my internship at SocioFuture, I participated in the full development cycle of a vision-guided Physical RPA project. My work connected perception, computer interaction, workflow integration, and explicit stop conditions into a dependable automation flow. Source code and operational details are not linked publicly.

`Computer vision` · `Human-in-the-loop automation` · `Reliability` · `Team development`

### [Knowledge-Graph Recommendation System](https://github.com/Chenqiang-Zhang/Am)

An experimental recommendation system built on Amazon Reviews'23, Neo4j, and verifiable graph paths, with LLMs used for intent and attribute extraction rather than unconstrained query generation.

`FastAPI` · `Neo4j` · `Knowledge graphs` · `Recommender systems`
